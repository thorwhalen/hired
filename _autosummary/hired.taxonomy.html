hired.taxonomy#

Skills taxonomy (ESCO + O*NET) and skill adjacency for alignment’s Axis A.

Strengthens transfer distance beyond keyword match and LLM judgment with two signals, blended as alpha * cosine + (1 - alpha) * graph:

  • a relatedness graph learned from which skills occupations require together (ESCO occupation↔skill links, O*NET technology and K/S/A ratings) — pure Python;

  • label embeddings (the embeddings extra) for similarity and for skills absent from both taxonomies.

Nothing is vendored: build the taxonomy once into the data root, then query it:

from hired.taxonomy import build_skill_index, load_skill_index
build_skill_index()                 # or `hired build-skill-index`; tens of minutes
idx = load_skill_index()
idx.suggest_adjacency("PyTorch", ["TensorFlow", "Excel"])

ESCO (© European Union) and O*NET (USDOL/ETA) data are used under CC BY 4.0; see hired.taxonomy.base.ATTRIBUTION, written next to the data as NOTICE.md. Research basis: misc/docs/research/skills-taxonomy-and-adjacency.md.

Bases: object

Lookup and adjacency over taxonomy nodes, edges and (optional) vectors.

>>> from hired.taxonomy.base import SkillNode
>>> nodes = [SkillNode(id='s:py', label='Python (computer programming)',
...                    alt_labels=['Python'], source='s'),
...          SkillNode(id='s:ml', label='machine learning', source='s'),
...          SkillNode(id='s:cook', label='cooking', source='s')]
>>> idx = SkillIndex(nodes, {'s:py': [('s:ml', 0.6)], 's:ml': [('s:py', 0.6)]})
>>> idx.lookup('python')[0].node.id
's:py'
>>> p = idx.proximity('Python', 'machine learning')
>>> p.score, p.alpha, p.transferability().value
(0.6, 0.0, 'contextual')
>>> idx.proximity('Python', 'cooking').score
0.0

lookup(text, *, k=5, min_score=0.5)[source]#

Nodes best matching text: exact label, alt label, token overlap, embedding.

Token and embedding matches are ranked by kind_weights times their similarity to text: the label embedding’s cosine when vectors exist (so a token overlap that is only a shared word ranks low), else the token score. Match.score stays the stage’s own score.

>>> from hired.taxonomy.base import SkillNode
>>> idx = SkillIndex([
...     SkillNode(id='o:s', label='Sales software', source='o', kind='technology'),
...     SkillNode(id='e:s', label='sales activities', source='e'),
... ], {})
>>> idx.resolve('sales').label
'sales activities'
