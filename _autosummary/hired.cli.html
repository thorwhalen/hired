hired.cli#

Command-line operations for the candidate-knowledge + JD-alignment workflow.

Each function here is a plain, importable operation — no CLI library is imported — and CLI_FUNCS is the single source of truth for what the hired command exposes (see hired.__main__, which projects it onto a parser with cw).

Every operation takes a keyword-only user (--user on the command line), resolved by hired.persistence.resolve_user(): the given name, else $HIRED_USER, else "me". So a single-candidate setup needs no flag at all, and several candidates coexist under users/<user>/.

The intelligence stays outside: ingest takes fact records an extractor (the hired-profile-ingest subagent, or an LLM) already produced, and analyze takes an analyst-drafted report; the commands validate, derive what is deterministic, and persist.

>>> import os, json, tempfile
>>> os.environ['HIRED_DATA_DIR'] = tempfile.mkdtemp()
>>> work = tempfile.mkdtemp()
>>> cv = os.path.join(work, 'cv.md')
>>> _ = open(cv, 'w').write('I built ML pipelines in Python.')
>>> recs = os.path.join(work, 'facts.json')
>>> _ = open(recs, 'w').write(json.dumps([{'statement': 'Builds ML pipelines',
...     'category': 'skill', 'quote': 'built ML pipelines'}]))
>>> ingest(recs, source=cv, user='alice')['added']
1
>>> users()
['alice']
>>> facts(user='alice')
['Builds ML pipelines']

hired.cli.analyze(report, jd, *, job_id=None, company=None, user=None)[source]#

Finalize an analyst-drafted alignment report (JSON) and save it under engagement jd.

Every requirement is re-classified with the deterministic rubric, bucket counts, blocking gaps and the ranked clarifying questions are rebuilt, and the report is saved (the previous version of the same job’s report is archived). Prints the saved job id and the resulting verdict line.

hired.cli.ingest(records, *, source=None, user=None)[source]#

Add extracted fact records (a JSON list) to a candidate’s knowledge base.

records is a JSON file holding a list of {"statement", "category", "tags", "confidence", "quote", "locator", "is_negation"} dicts. With --source (a raw-source key, or a file path, which is stored first) the facts cite that source, their quotes are checked against its text, and a re-ingest of the same source supersedes the facts of the previous one. Without it, the facts are recorded as externally sourced.

Return type:

dict[str, Any]
